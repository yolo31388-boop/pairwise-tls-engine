# 游戏内TLS/SSL加密与证书系统

## 项目描述

游戏内TLS/SSL加密与证书系统的bug修复项目。核心模块 `security/tls_engine.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 握手完全没做不能建立安全连接
- 证书验证完全没做任意证书都能通过
- 加密完全没做数据都是明文传输
- 密钥交换完全没做密钥是明文传输的
- 会话恢复完全没做每次都重新握手

## 运行测试

```bash
python -m pytest tests/test_tls_engine.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
